# Components

Feature-oriented folders:

- `layout/` — shell, bottom nav, theme
- `shared/` — GlassCard, SectionHeader
- `dashboard/` — `HomeClient` (home dashboard)
- `workouts/` — gym / body map / workout editors
- `recipes/` — recipe browsing and diet onboarding
- `routine/` — weekly planner, reminders, checklist UI
- `progress/` — charts
- `settings/` / `profile/` / `health/` — account surfaces

Prefer composing new UI inside the active feature client rather than adding unused scaffold widgets.
