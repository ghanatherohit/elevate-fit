## Overview

**Elevate Fit** is a web application designed to provide a seamless book browsing and purchasing experience for users, and a robust inventory management interface for administrators.

---

## Features

### For Users
- **Browse Books:** Explore a catalog of books by various filters and categories
- **Book Details:** View detailed information about each book
- **Add to Cart:** Easily add/remove books to/from a shopping cart
- **Purchase Workflow:** Secure checkout for purchasing selected books
- **Order History:** View orders previously placed

### For Admins
- **Inventory Management:** Add, update, and remove books from inventory
- **Order Management:** View and manage customer orders
- **User Management:** (If implemented) Manage registered users

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ghanatherohit/elevate-fit.git
cd elevate-fit
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
```

### 3. Start the Development Server

```bash
npm run dev
# or
yarn dev
```

Visit `http://localhost:3000` in your browser to view the app.
